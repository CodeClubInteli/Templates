# Repositório de Templates — CodeClub

Bem-vindo(a) ao repositório oficial de **Templates Educacionais** do CodeClub!

Este repositório reúne os modelos padronizados usados pela Diretoria Educacional para organizar as atividades do projeto: planos de aula, cronogramas, guias e documentos de apoio.

Nosso objetivo é garantir que toda a equipe trabalhe de forma colaborativa, organizada e alinhada.


## 📁 Estrutura do Repositório

    /Templates-CodeStart
        │
        ├── Plano-de-Aula.md → Modelo padrão para planos de aula
        ├── Conteudo-da-Aula.md → Modelo para adição do conteúdo escrito da aula
        ├── anexos/ → Pasta para adição de materiais úteis para as aulas. 


---

## 🛠 Como Usar

1️⃣ **Baixe ou copie o template desejado.**  
Você pode clicar no arquivo no GitHub e usar o botão `Raw` para copiar, ou baixar diretamente.

2️⃣ **Adicione o Template no repositório do Projeto indicado**  
No repositório do projeto, adapte os templates indicados nesse repositório.

3️⃣ **Salve no repositório principal.**  
Depois de preencher, salve o arquivo renomeando de acordo com o conteúdo específico (ex.: `plano_aula_01.md`).

4️⃣ **Abra um Pull Request.**  
Se estiver trabalhando em uma nova versão ou atualização, envie suas alterações para revisão.


## 🧩 Templates Disponíveis

✅ **Plano do Code Start** Estrutura com objetivos, atividades, materiais, dicas para monitores.  
✅ **Cronograma Semestral:** Quadro geral das aulas, temas e responsáveis.  
✅ **Ata de Reunião:** Modelo para registrar discussões, decisões e próximos passos.  
✅ **Template de Feedback:** Documento para coletar percepções e sugestões dos participantes.  
✅ **Guia para Monitores:** Orientações gerais para apoiar quem atua nas aulas.
